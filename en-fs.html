FactorialSurvey R package

FactorialSurvey is an R toolkit for factorial survey experiments (FSE)—a vignette-based approach to measure preferences and intentions. It supports a practical workflow from D-efficient design and power analysis through estimation to WTP analysis. It is available on CRAN.

Features

Design

Build D-efficient sets of vignettes with fs_defficient(). fs_efficiency() and fs_design_eval() report D- and A-efficiency for any design, including one built elsewhere.

Fielding

Render vignettes as text with fs_vignette_text(), assign blocks and carryover-balanced orders with fs_assign(), and write them out for survey platforms with fs_export().

Sample size

Simulate the survey before fielding with fs_power() and fs_simulate_ratings() to see how often each effect would be detected and how precise WTP would be.

Estimation

Beta regression for bounded ratings such as 0–10 scales (fs_betareg()) and logit for yes/no responses (fs_logit()), with standard errors clustered by respondent (cluster = ~ id). summary() reports fit statistics and average marginal effects.

Willingness to pay

Marginal WTP for each attribute with fs_mwtp(), and expected WTP for complete scenarios with fs_ewtp(). Expected WTP is computed with WTP truncated at zero. Intervals by the delta method, Krinsky–Robb or Fieller.

Plots

plot() methods for models, WTP and power results, built on ggplot2, with theme_fs() for black-and-white print.

Installation

Install the released version from CRAN. It requires R 4.1 or later.

install.packages("FactorialSurvey")

The development version can be installed from GitHub.

# install.packages("remotes")
remotes::install_github("tanakak/FactorialSurvey")

Getting started

The package vignette Getting started with FactorialSurvey walks through the whole workflow with lunch boxes as the example: designing the vignettes, deciding how many respondents are needed, estimating the model and computing willingness to pay. Once the package is installed, it can also be opened in R with vignette("FactorialSurvey", package = "FactorialSurvey").

The package includes bento, real ratings of eight lunch-box vignettes by 48 students on a 0–10 scale, so you can try it right after installation:

library(FactorialSurvey)

# 'bento': 48 students rated 8 lunch-box vignettes on a 0-10 scale
fit <- fs_betareg(rating ~ main + side + info + price, data = bento,
                  cluster = ~ respondent, compute_me = FALSE)
summary(fit)

# Marginal willingness to pay (yen) for each attribute
fs_mwtp(fit, price = "price")
  • Each function is documented in the reference manual (PDF).
  • To start from raw survey files—reading a CSV and reshaping it for analysis—see fs_demo.R on GitHub.

Citation

If you use the package, please cite both the package and the working paper that describes its methods. The package citation is also shown by citation("FactorialSurvey") in R.

  • Tanaka, K. (2026). FactorialSurvey: Design and Analysis of Factorial Survey (Vignette) Experiments. R package version 0.3.0. DOI
  • Tanaka, K. (2025). A Unified Framework for Estimating Willingness to Pay Using Factorial Survey Experiments. SSRN Working Paper. SSRN

For an application of expected WTP for complete policy scenarios (fs_ewtp()), see:

  • Tanaka, K., Dill, J., McNeil, N., Geller, R., & Kondo, N. (2027). What Are Safer Streets Worth? Bridging Resident Preferences and Policy Design in Traffic Calming. Transportation Research Part A: Policy and Practice, 215, 105293. DOI
