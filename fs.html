FactorialSurvey Rパッケージ

FactorialSurvey は、要因サーベイ実験（factorial survey experiment, FSE）のためのRパッケージです。要因サーベイ実験は、条件を組み合わせた仮想の場面（ビネット）を回答者に評価してもらい、選好や行動の意図を測る方法です。D効率的な計画づくりと標本サイズの検討から、推定、支払意思額（WTP）の分析までを一続きで行えます。CRAN（Rの公式のパッケージ公開サイト）から入手できます。

主な機能

計画づくり

fs_defficient() で、D効率的なビネットの組み合わせを作ります。fs_efficiency() と fs_design_eval() は、ほかのツールで作った計画も含めて、D効率とA効率を示します。

調査での配布

fs_vignette_text() でビネットを文章にし、fs_assign() でブロックと提示順（順序の影響が偏らないもの）を割り当て、fs_export() で調査システム向けに書き出します。

標本サイズ

実施の前に fs_power() と fs_simulate_ratings() で調査を模擬し、それぞれの効果をどのくらいの確率で検出できるか、WTPをどの程度の精度で推定できるかを確かめます。

推定

0〜10点のように上限と下限のある評価にはベータ回帰（fs_betareg()）、はい・いいえの回答にはロジット（fs_logit()）を使います。標準誤差は回答者ごとにクラスター化できます（cluster = ~ id）。summary() で適合度と平均限界効果を表示します。

支払意思額

fs_mwtp() で属性ごとの限界WTPを、fs_ewtp() で場面全体の期待WTPを求めます。期待WTPは、WTPがマイナスにならないものとして計算します。信頼区間はデルタ法、Krinsky–Robb 法、Fieller 法から選べます。

図

推定結果、WTP、検出力の結果には plot() があります（ggplot2 を使用）。白黒で印刷するためのテーマ theme_fs() も用意しています。

インストール

CRANから、ほかのRパッケージと同じようにインストールできます。R 4.1以上で動きます。

install.packages("FactorialSurvey")

CRANに出す前の開発版は、GitHubから入れられます。

# install.packages("remotes")
remotes::install_github("tanakak/FactorialSurvey")

使い方

使い方は、パッケージの解説 Getting started with FactorialSurvey（英語）にまとめています。弁当を例に、ビネットの設計、必要な回答者数の検討、推定、支払意思額の計算までを順に試せます。インストール後は、R で vignette("FactorialSurvey", package = "FactorialSurvey") と入力しても開けます。

パッケージには、学生48人が弁当のビネット8つを0〜10点で評価した例題のデータ bento が入っているので、インストールしてすぐに次のように試せます。

library(FactorialSurvey)

# 'bento': 48 students rated 8 lunch-box vignettes on a 0-10 scale
fit <- fs_betareg(rating ~ main + side + info + price, data = bento,
                  cluster = ~ respondent, compute_me = FALSE)
summary(fit)

# Marginal willingness to pay (yen) for each attribute
fs_mwtp(fit, price = "price")
  • 関数ごとの説明は リファレンスマニュアル（PDF、英語） にあります。
  • 調査で集めたCSVを読み込み、分析できる形に並べ替えるところから試したい場合は、fs_demo.R（GitHub）を使ってください。

パッケージを紹介する英語論文と、要因サーベイ実験についての日本語の教科書を準備しています。
